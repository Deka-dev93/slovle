# Словле — Wordle на русском

Бесплатная браузерная игра: угадайте загаданное слово из 5 букв за 6 попыток.

**Играть:** https://deka-dev93.github.io/slovle/

## Как играть

1. Введите существующее русское слово из 5 букв и нажмите **Ввод** (Enter).
2. После каждой попытки буквы меняют цвет:
   - 🟩 зелёная — буква есть в слове и стоит на своём месте;
   - 🟨 жёлтая — буква есть в слове, но стоит в другом месте;
   - ⬛ серая — такой буквы в слове нет.
3. У вас есть 6 попыток. Угадайте слово, пока они не закончились.

Буква «ё» считается как «е», отдельно вводить её не нужно.

## Режимы

- **Слово дня** — одно слово для всех игроков, меняется раз в сутки (в полночь по времени игрока). Если закрыть страницу посреди партии, прогресс сохранится.
- **Случайное** — играйте сколько угодно раз, каждая партия с новым словом.

## Возможности

- Экранная клавиатура, на которой подсвечиваются уже использованные буквы, и ввод с обычной клавиатуры.
- Статистика: число игр, процент побед, текущая серия, рекорд и график по числу попыток.
- Кнопка «Поделиться» копирует результат цветными квадратиками, без спойлеров.
- Окно с правилами при первом запуске.
- Светлая и тёмная темы подстраиваются под систему.
- Работает на телефоне и компьютере. Статистика и прогресс хранятся только в вашем браузере.

## Технические детали

- Игра — один файл [`index.html`](index.html): HTML, CSS и JavaScript без зависимостей и без сборки. Рядом лежит словарь [`words.txt`](words.txt).

## Словари

В игре два списка слов:

- **Загадываемые слова** — около 700 распространённых существительных. Они находятся в константе `LIST` в `index.html`. Чтобы добавить слова, дописывайте их через пробел: слова не из 5 букв игра отбрасывает сама.
- **Допустимые слова** — файл [`words.txt`](words.txt), около 25 тысяч слов из 5 букв во всех формах. По нему игра проверяет ваши попытки и отвечает «Нет такого слова в словаре» на выдуманные комбинации. Если файл не загрузился, игра принимает любые 5 букв.

Файл `words.txt` получен из списка [danakt/russian-words](https://github.com/danakt/russian-words) (лицензия MIT): оставлены только слова из 5 букв, все буквы приведены к нижнему регистру, «ё» заменена на «е». В списке есть имена собственные и редкие слова, поэтому иногда игра принимает не совсем обычное слово.

## Известные ограничения

- Слово дня меняется в полночь по местному времени игрока, поэтому у людей в разных часовых поясах оно меняется в разное время.
- Словарь допустимых слов не идеален: в нём встречаются имена, географические названия и редкие слова.
